# Requerimientos del Sistema – IcarApp

## 🎯 Objetivo del Documento
Definir los requerimientos funcionales del MVP de IcarApp, alineados con
la visión de libertad, versatilidad, sencillez y accesibilidad gratuita,
sirviendo como base para flujos, arquitectura y desarrollo.

---

## 🧩 Alcance General
El sistema permite a los usuarios registrar, modificar y visualizar
información relacionada con su entrenamiento y nutrición, manteniendo
control total sobre sus datos y cálculos, sin flujos rígidos ni
restricciones artificiales.

---

## 👤 Actores

### Usuario
Persona que utiliza la aplicación para registrar y analizar su
entrenamiento y nutrición.

No existen roles adicionales en el MVP.

---

## 🏋️ Requerimientos Funcionales – Entrenamiento

### Gestión de Rutinas
- Como usuario quiero crear rutinas de entrenamiento
- Como usuario quiero editar y eliminar rutinas
- Como usuario quiero asignar rutinas a días específicos

### Gestión de Ejercicios
- Como usuario quiero registrar ejercicios dentro de una rutina
- Como usuario quiero definir el orden de los ejercicios
- Como usuario quiero reutilizar ejercicios en distintas rutinas

### Series y Repeticiones
- Como usuario quiero registrar series por ejercicio
- Como usuario quiero definir repeticiones, peso y observaciones
- Como usuario quiero modificar series libremente

### Notas y Observaciones
- Como usuario quiero agregar notas por ejercicio
- Como usuario quiero consultar notas de entrenamientos anteriores

### Tiempo y Seguimiento
- Como usuario quiero usar un contador de tiempo personalizable
- Como usuario quiero ver el historial de entrenamientos realizados

### Visualización de Progreso
- Como usuario quiero visualizar mi progreso mediante gráficas
- Como usuario quiero comparar entrenamientos entre fechas
- Como usuario quiero ver el progreso por ejercicio

---

## 🍽️ Requerimientos Funcionales – Nutrición

### Configuración de Objetivos
- Como usuario quiero definir mi gasto calórico de mantenimiento
- Como usuario quiero definir mis objetivos de macronutrientes
- Como usuario quiero modificar estos valores en cualquier momento

### Registro de Comidas
- Como usuario quiero registrar comidas diarias
- Como usuario quiero definir calorías y macros por comida
- Como usuario quiero editar o eliminar comidas registradas

### Cálculo Diario
- Como usuario quiero ver el total diario de calorías
- Como usuario quiero ver el total diario de macronutrientes
- Como usuario quiero comparar consumo real vs objetivos

### Visualización
- Como usuario quiero visualizar el consumo diario de forma clara
- Como usuario quiero consultar registros nutricionales pasados

---

## 🔄 Requerimientos Transversales

### Persistencia
- Como usuario quiero que mis datos se guarden de forma segura
- Como usuario quiero acceder a mi información en cualquier momento

### Edición Libre
- Como usuario quiero modificar cualquier registro
- Como usuario quiero experimentar con distintos valores

### Simplicidad de Uso
- Como usuario quiero realizar acciones con pocos pasos
- Como usuario quiero una interfaz clara y directa

---

## 🚫 Fuera de Alcance (MVP)
- Integraciones con dispositivos externos
- Recomendaciones automáticas
- Rutinas o dietas predefinidas
- Funcionalidades sociales
- Monetización o suscripciones

---

## 🧠 Notas de Producto
- El sistema no impone límites artificiales a los cálculos
- El usuario tiene control total sobre valores y objetivos
- La aplicación actúa como herramienta, no como guía prescriptiva

---

## ✅ Criterio de Completitud del MVP
El MVP se considera completo cuando:
- El usuario puede registrar y visualizar entrenamientos y nutrición
- Puede modificar libremente sus datos
- Puede analizar su progreso de forma visual
- Puede usar la aplicación sin restricciones de pago
