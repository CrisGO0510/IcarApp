# IcarApp

## 🧩 Problema
Las personas que entrenan de forma constante suelen llevar el registro
de su progreso de entrenamiento y nutrición de manera desordenada
(o directamente no lo llevan), lo que dificulta medir avances reales
y mejorar hábitos a largo plazo.

Las soluciones existentes suelen ser complejas, poco intuitivas
o demasiado genéricas.

## 🎯 Objetivo
Permitir que el usuario lleve un registro simple y claro de su
entrenamiento y nutrición diaria, facilitando el seguimiento del progreso
y fomentando hábitos saludables de forma sostenida.

## 👤 Usuarios
Personas que entrenan entre 3 y 5 veces por semana y desean mejorar
su condición física, pero buscan una herramienta práctica,
rápida y fácil de usar desde el móvil.

## 🚀 Alcance (MVP)

El MVP de IcarApp busca validar una experiencia completa de seguimiento
de entrenamiento y nutrición, priorizando la visualización clara del progreso
y la facilidad de uso.

Por este motivo, el MVP incluye funcionalidades de registro **y**
visualización desde la primera versión.

### 🏋️ Entrenamiento
- Registro de rutinas
- Registro de ejercicios por día
- Registro de series y repeticiones
- Sistema de notas por ejercicio
- Contador de tiempo personalizable
- Visualización de progreso mediante gráficas
- Calendario de entrenamientos

### 🍽️ Nutrición
- Registro de gasto calórico diario de mantenimiento
- Registro de objetivos de macronutrientes
- Registro de comidas
- Registro de macronutrientes por comida
- Cálculo total diario de calorías y macros

Este alcance se considera cerrado para el MVP y no incluye
integraciones externas ni funcionalidades sociales.

## 🛠️ Stack
- **Frontend:** Vue.js 3 (Composition API)
- **Mobile/PWA:** Quasar Framework

Se eligió este stack por la velocidad de desarrollo que ofrece Quasar,
su excelente ecosistema de componentes, y Vue 3 por su curva de aprendizaje
suave y reactividad moderna. Además, Quasar permite generar apps
multiplataforma (web, mobile, desktop) desde una sola base de código.
